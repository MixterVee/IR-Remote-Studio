IR REMOTE STUDIO — WINDOWS 1.0.0 RELEASE CANDIDATE 2
====================================================
Portable Windows x64. No Python installation is needed.

FIRST RUN
---------
1. Extract the entire download ZIP into a folder, then run
   IR-Remote-Studio.exe.
2. By default the app stores commands and buttons in:
      Documents\IR Remote Studio\library.json
   Your library from beta versions is retained. Before major changes,
   choose File > Back up library JSON.
3. File > Export Device (.irplus) creates an IRplus-compatible remote
   that can be imported into the IRplus Android app.

SOFABATON U1 LEARNING — WORKING BASELINE
---------------------------------------
This release preserves the exact learning backend and dialog worker
from v0.3.3, which successfully learned 4 commands on a physical U1.
The exported .irplus commands were verified in IRplus.

1. Close the official SofaBaton phone app.
2. Put the U1 in Bluetooth pairing mode (- and E together).
3. Click SofaBaton U1... The app scans, identifies, and automatically
   connects a matching U1. After connection the popup closes.
4. Select or create a device and a button on the main screen.
5. Click Capture selected button (SofaBaton U1).
6. When the U1 shows Learning, point the original IR remote at it
   and press the command. A successful signal is saved immediately.
7. After a successful, disk-verified save, choose Existing button,
   New button, or Finish. Existing keeps the previous button's
   name and layout and adds another sample. Finish leaves U1 connected.

No typed LEARN 8 confirmation, experimental profile creation command,
or return trip to the Bluetooth connection window is needed.

IMPORTANT: Learning uses the U1's internal slot 8. The program
backs up its previous IR waveform before use under
Documents\IR Remote Studio\U1-Learn-Backups\
That backup does NOT restore the U1's complete programming or profile.

USB IR LEARNING
---------------
1. Attach one supported USB IR learner.
2. In Receiver choose Auto, a direct Harmony 300/350 HID learner, a
   legacy Concordance option, or an experimental Ocrustar adapter.
3. Click Detect USB to scan supported USB IDs.
4. Click Connect USB to run a protocol handshake. The verification
   USB session closes when finished; the green indicator means
   the last check succeeded, not an always-open session.
5. Select a device/button and click Capture selected button (USB).
6. Wait for the readiness message; send the original IR command.
   Valid commands save automatically. Export and test in IRplus.

Ocrustar/ElkSmart bulk USB is still experimental and may require
separate Windows driver access. Do not swap drivers or flash remote
firmware without confirming the precise device identity.

CAPTURE STATUS AND CORRECTIONS
------------------------------
"Verified" means repeated samples agree. It does not mean the
controlled appliance was tested. "Raw IR (saved)" means a valid IR
signal was recorded but no recognized NEC command was decoded.
Those raw samples can still be exported to IRplus.

For a mismatched sample, Undo last removes the newest sample only.
Clear all samples for this button... keeps the button name and layout.
Both change local library entries only, not the U1 programming.

LAYOUT EDITOR AND SAVED POSITION
--------------------------------
The main window manages devices, buttons and learning. Layout editor...
handles appearance: Move Up, Move Down, button width and preview.
Save layout applies the changes and Cancel discards them.

The Layout Editor remembers its position and size across launches in
Documents\IR Remote Studio\layout-editor-window.json.
If an old monitor is disconnected, it opens somewhere visible.

OTHER FEATURES
--------------
* File > Back up library JSON and Restore library backup
* Import/export IR capture JSON and complete .irplus remotes
* Inspect samples and choose the best matching capture
* Help > About IR Remote Studio (version, supported backends,
  project/license information and data folder)
* Bluetooth Troubleshooting (optional stored-slot read,
  inspect services, OS pairing and log export)

SAFETY AND DIAGNOSTICS
----------------------
The application does not transmit learned IR directly from Windows;
export to IRplus for testing/transmission using compatible hardware.
The executable is unsigned; Windows SmartScreen may warn about an
unknown publisher. Only download from the project's official GitHub
repository.

In case of failures, back up Documents\IR Remote Studio\library.json
before modifying or restoring library data. Never assume a raw U1
slot-8 backup restores every button/profile setting.
