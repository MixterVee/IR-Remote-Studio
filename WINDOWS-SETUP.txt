IR Remote Studio v0.1.6 - Windows 11 x64
========================================

1. Extract the ZIP artifact from GitHub Actions onto your Windows computer.
2. Keep the official/unofficial Concordance v1.5.0.2 install at:
   C:\Program Files (x86)\Concordance\libconcord-6.dll
3. Connect a compatible Harmony IR-learning remote to a working USB port.
4. Close Concordance and any other application accessing the Harmony.
5. Double-click IR-Remote-Studio.exe.
6. Add a device and a custom-labeled button, then choose Check Harmony IR learner.
7. Select the button, click Capture, point original IR remote at the
   Harmony learning receiver (5-10 cm) and press the button briefly.
8. Capture again for confidence, then Export .irplus.
9. Import the .irplus file in irplus on your compatible phone.

Existing Xflyee captures: File > Import capture JSON. The previously
verified Xflyee .irplus file can also be imported directly.

Capture uses 32-bit Windows PowerShell in a separate process, so a native
DLL problem cannot terminate the GUI. It doesn't rewrite the Harmony.

Your device library is stored in:
  %USERPROFILE%\Documents\IR Remote Studio\library.json

This is an early Windows beta. The capture interface has been tested
previously with a Harmony 350, but this newly packaged application
requires user hardware testing. Android application is a later milestone.

Project: https://github.com/MixterVee/IR-Remote-Studio

Supported Harmony devices: see README.md and irstudio/harmony_models.json.
The Harmony 700/700i are experimental. Models without documented IR learning
capability are blocked; remote identification alone is insufficient.

New in v0.1.6: File > Restore library backup (creates automatic safety backup),
Review captures to select one for export, and Layout editor to set button widths.
A Harmony USB error 11 may indicate missing batteries, unsuitable USB cable,
or a failed USB port. Try known-good hardware before changing drivers.

Layout fix in v0.1.6: re-export .irplus files to add explicit row spacer
entries and prevent narrow buttons from overflowing beside wide buttons.

NEW IN v0.1.6
==============
Open a device, click Layout editor and select Phone Preview or Grid Preview.
Change button width (2/3/4/6/12 columns), then Save layout and Export Device (.irplus).
Phone preview supports Small/Normal/Large screen and text sizes and Dark/Light
appearance. Only buttons with captured/imported IR codes appear in the preview.
The exported layout rows are shared with the preview; actual phone typography
may differ. Capture status reports Verified only for 2+ matching samples.
