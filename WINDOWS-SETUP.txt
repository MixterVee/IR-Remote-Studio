IR Remote Studio 0.2.7-beta — Windows 11 x64
================================================

FIRST STANDALONE LEARNER TEST
-----------------------------
This beta adds direct USB learning WITHOUT requiring Concordance for
supported Harmony 300/350 and an experimental Ocrustar/ElkSmart dongle
adapter. Previous Windows features and the Concordance backend remain.

1. Download the v0.2.7-beta Windows x64 ZIP from GitHub Actions.
2. Extract the files and launch IR-Remote-Studio.exe.
3. Connect ONE supported USB IR learning device.
4. From "IR learning hardware", choose one of:
   • Auto detect supported learner
   • Harmony 300/350 — standalone HID
   • Ocrustar / ElkSmart — USB bulk (experimental)
   • Concordance — legacy DLL
5. In the prominent IR LEARNER CONNECTION panel, click "Refresh USB"
   to detect supported device IDs WITHOUT sending any commands.
   RED NOT CONNECTED means detection/verification has not succeeded.
   AMBER USB DETECTED means the USB identity is recognized, but the
   actual protocol handshake has NOT been verified yet.
6. Click "Connect / Retry". GREEN READY — CONNECTION VERIFIED means
   the selected learner's protocol handshake has succeeded.
   This verification USB session then closes normally; it does not
   maintain a permanently open connection. If the handshake fails,
   RED CONNECTION FAILED — RETRY appears with reconnection guidance.
   A connection-failure popup also reminds you to check batteries\n   in any battery-powered Harmony/source remote, then explains\n   unplug/reconnect, trying another\n   USB port, then Refresh USB and Connect / Retry. The original USB\n   error is also shown, with longer diagnostics stored in Logs.
7. Select/create a device and button; choose "Capture selected button."
8. WAIT for the separate GREEN READY — PRESS A BUTTON NOW indication;
   this confirms that the receiver is actually armed. Point a source
   remote at the learner, press and release one button. When the
   capture finishes, the USB session closes. Valid captures are
   automatically saved
   to the local app library after successful protocol cleanup.
9. Click "Save" to confirm and finish learning this button; OR
   click "Save & Learn another" to create and capture another button.
   Both options safely persist the current button; no duplicate captures.
10. Export .irplus to test the button on the Android phone or in IRPlus.

SUPPORTED STANDALONE BACKENDS
-----------------------------
Harmony 300/350 (USB VID:PID 046D:C124)
   Shared direct-HID learning protocol with 64-byte MH reports. Tested
   successfully on Android Harmony 300; Windows HID transport and the
   Harmony 350 device still require physical verification.

Ocrustar/ElkSmart D226/D552 (USB VID:PID 045C:02AA)
   Experimental bulk USB learner. This research protocol supplies
   timing data WITHOUT the carrier frequency, so the app assumes 38 kHz.
   Replaying on the real device is mandatory before treating it as
   a reliable command. Your newly ordered Ocrustar unit may differ;
   verify its actual USB VID/PID and interface before sending learning
   commands. Do not replace USB drivers before inspecting the device.

Other USB IR dongles
   Not automatically compatible. Hardware detection/learning requires
   an adapter matching the exact USB protocol and capabilities.
   Never send Harmony or Ocrustar commands to an unknown dongle.
   Some IR adapters transmit only and cannot learn IR codes.

WINDOWS USB DRIVER CAUTION
--------------------------
HID Harmony devices should use their normal Windows HID driver.
The Ocrustar bulk protocol may require WinUSB/libusb access; some
Windows drivers block the PyUSB backend. DO NOT automatically replace
a device driver or use Zadig until its precise USB identity has been
verified and you understand the effects on the original software.
A failed driver access returns a diagnostic rather than changing USB
configuration.

LEGACY CONCORDANCE OPTION
-------------------------
Select "Concordance — legacy DLL" for the previous separate x86
PowerShell/Concordance learning worker, useful for other documented
Harmony models. That backend requires an existing local installation:
  C:\Program Files (x86)\Concordance\libconcord-6.dll
IR Remote Studio does not distribute or install libconcord.

LIBRARY & TEST LOGS
-------------------
Library (normal update preserves existing data):
  %USERPROFILE%\Documents\IR Remote Studio\library.json
Logs:
  %USERPROFILE%\Documents\IR Remote Studio\Logs

Before using this beta, File > Back up library JSON is recommended.
Layout editor, capture comparison, import/export, restore and backup
remain available.

SAFETY
------
The direct backends only use the known transient IR-receiver commands
for recognized devices. They do NOT modify Harmony firmware or existing
button programming, and do NOT transmit IR automatically.
Do not run Concordance and the direct receiver simultaneously.
If detection/handshake fails, send the exact error and associated
direct-*.log or ocrustar-*.log file for diagnosis.

Project: https://github.com/MixterVee/IR-Remote-Studio

SOFABATON U1 BLUETOOTH RESEARCH (EXPERIMENTAL)
----------------------------------------------
The separate "SofaBaton U1 Bluetooth..." button in the Windows IR learner
connection panel opens a safe diagnostic window. It does NOT yet allow
IR learning, reading/saving the U1's commands, or programming the U1.

1. Turn on Bluetooth on the Windows PC and install working AA batteries
   in the SofaBaton U1.
2. Close the official SofaBaton app if it is connected to the remote.
3. On the U1, hold the "-" and "E" buttons to display "Pairing".
4. Open "SofaBaton U1 Bluetooth..." and click "Scan Bluetooth".
5. Examine the names (including unnamed BLE devices). Only if you can
   identify your U1, select it and choose "Inspect selected (read-only)".
6. Approve the explicit confirmation. The app temporarily connects to
   enumerate GATT service/characteristic UUID metadata and disconnects.
   It never reads characteristic values, subscribes to notifications,
   writes commands, changes profiles, or initiates Bluetooth pairing.
7. Click "Copy report" or "Save report...". Review it before sharing:
   it may contain local Bluetooth addresses for nearby devices.

This is BLE protocol research only. The U1's proprietary BLE commands and
IR-learning workflow have NOT been identified. Classic Bluetooth controls
and the SofaBaton X-series hub protocols are not interchangeable with
U1 app configuration. The existing Harmony/Ocrustar/Concordance backends
are unaffected. Windows BLE scanning may require suitable PC Bluetooth
hardware and Windows permissions.

SOFABATON U1 — READ AN EXISTING SAVED IR CODE (NEW IN 0.2.6)
------------------------------------------------------------
This is NOT new IR learning. It reads back an existing command that
the U1 already stores, as a safe stepping stone toward native learning.
Only the documented device-info (0x01) and read-command (0x0C) inquiries
are transmitted. No U1 profile updates, learning start/finish operations,
or configuration writes are sent.

1. Back up the IR Remote Studio Windows library first.
2. Close the official SofaBaton app (so Windows can use the BLE session).
3. Connect to a U1 with working batteries and open
   "SofaBaton U1 Bluetooth..." from the main window.
4. Scan Bluetooth and identify your SB-prefixed U1 advertising FFF0.
5. Choose a U1 slot containing a known stored IR code, initially 7
   (previously observed in official-app trace) or 8 (newly taught test).
6. Click "Read stored IR (test)" and approve the warning.
7. Wait for complete 0x0D fragments. The app checks the device identity,
   BLE service UUIDs, packet checksum, segment ordering, aggregate
   checksum, carrier frequency and timing validity. A failed/incomplete
   session is rejected without saving anything.
8. In the main IR Remote Studio window, select your destination device
   and button. Choose "Save to selected button" in the Bluetooth window.
9. Export that device as .irplus and verify playback on your Android phone.

The read request may not work on all U1 firmwares or Windows BLE adapters.
The U1 is NOT yet a native learner in IR Remote Studio. Do not experiment
with arbitrary firmware or configuration writes. Full direct learning is
a subsequent milestone requiring careful confirmation of start/end codes.

LAPTOP DISPLAY / TASKBAR RESIZING (0.2.7)
-----------------------------------------
Device and button actions are now bottom-anchored ahead of their lists,
so maximized laptop windows keep Add/Rename/Delete/Move/Layout editor
visible above the Windows taskbar. The lists shrink when vertical space
is limited instead of pushing action rows offscreen. The layout editor
also reserves its footer Save/Cancel, button-width controls and preview
status before allocating height to the expandable list/preview.
